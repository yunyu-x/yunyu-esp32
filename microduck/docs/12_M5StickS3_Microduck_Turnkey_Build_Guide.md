> **主控平台**：M5Stack M5StickS3（ESP32-S3 双核 @ 240MHz + 板载 BMI270 IMU + 0.85" 彩色屏幕）  
> **生产采购模式**：全淘宝外购（飞特 STS3215 舵机 + 淘宝 3D 打印代打 + 标准航模与五金配件）

## 一、 M5StickS3 硬件深度适配与架构拓扑

采用 **M5StickS3** 作为主控拥有巨大的手搓优势：
1. **天然省去外购 IMU 模块**：板载高性能博世 **BMI270** 六轴陀螺仪/加速度计，通过硬件 I2C 直连，免去飞线、焊接与传感器布线松脱风险；
2. **自带 0.85 寸彩色屏幕 (ST7789v2)**：不仅能作为机器人的交互“眼睛”（显示眨眼、注视、警戒等萌系表情），还能在行走时实时显示 14 关节温度、电池电压与步态周频；
3. **自带实体按键与蜂鸣器**：按键 A 一键启动/暂停步态，按键 B 切换行走模式或执行回零校准。

### M5StickS3 物理接口引脚定义表

| 接口 | M5StickS3 内部 GPIO | 信号名称 | 连接目标 (FE-URT-1 / 降压板) | 作用说明 |
| :--- | :---: | :---: | :--- | :--- |
| **Grove 接口** | **GPIO 2** | `UART1_TXD` | `FE-URT-1` 的 `RX` 信号端 | 1Mbps 发送目标位置与控制指令 |
| **Grove 接口** | **GPIO 1** | `UART1_RXD` | `FE-URT-1` 的 `TX` 信号端 | 1Mbps 接收舵机当前角度、速度与温度 |
| **Grove 接口** | - | `5V_IN` | Mini DC-DC 降压模块的 `+5V` 输出 | 为 M5StickS3 自身供电（绕过电池） |
| **Grove 接口** | - | `GND` | Mini DC-DC 降压模块的 `GND` | 共地基准 |
| **板载总线** | **GPIO 11 / 12** | `I2C_SDA / SCL` | 板载 **BMI270** | `M5.Imu` 库原生直读姿态角速度 |
| **板载按键** | **GPIO 41** | `BtnA` | 用户手按触发 | 单击：开步/停止；双击：校准归零 |

## 四、 开箱即用：M5StickS3 专属调机与自主行走固件

我们在 `adapters/` 中为你准备了两套量身定制的工程代码：

### 1. 舵机自动化编址与校准固件 (`adapters/m5sticks3_servo_tool.ino`)
- **功能**：将新买的单只舵机接在转接板上，开机后 M5StickS3 屏幕显示当前检测到的舵机 ID 和当前角度；
- **操作**：按按键 A 切换目标 ID（如 10、11...），按按键 B 一键将该舵机重写为目标 ID，并命令舵机电机自动归零转到 2048 中位！随后即可在保持通电锁定状态下拧入舵盘。

### 2. 50Hz 律动 CPG 自主行走固件 (`adapters/m5sticks3_cpg_walk.ino`)
- **功能**：装配完毕后烧录此程序：
  - 屏幕显示动态小鸭眼睛，并显示当前 2S 电池实时电压与摆频；
  - 板载 BMI270 读取机器人倾角，防止跌倒；
  - 运行 50Hz CPG（中枢模式发生器）律动方程，左右腿以 180° 相位差交替摆动，带动整机在桌面上自主走动！
  - 按键 A 单击：“开始走路 / 站立待机”平滑过渡切换。
