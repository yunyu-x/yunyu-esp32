## 3. 舵机标定与组装次序 (Assembly Workflow)

```mermaid

    Step1["步骤 1: 舵机单体电气编址<br/>(逐个烧录 ID 10~14, 20~24, 30~34)"] --> Step2["步骤 2: 软件控制舵机回零<br/>(Goal Position = 0)"]
    Step2 --> Step3["步骤 3: 舵盘机械对中安装<br/>(肉眼最佳对准后锁紧螺丝)"]
    Step3 --> Step4["步骤 4: 骨骼组件分模块拼装<br/>(双腿模块 -> 躯干模块 -> 头部模块)"]
    Step4 --> Step5["步骤 5: 电气线束梳理与母线并联<br/>(防绞线余量留存)"]
    Step5 --> Step6["步骤 6: 软硬件零点偏置校准<br/>(写入 duck_config.json)"]
```

### 3.1 组装避坑要点指南

1. **绝对不要在未通电回零的情况下安装舵盘**：
   - 舵机出厂位置并不一定是机械零位；
   - 必须先通过代码（`configure_motor.py` 或 ESP32 标定程序）将舵机指令位置设为 `0`，让电机转到电气中心，然后再卡入舵盘并对准标记线。
2. **金属螺丝拧入舵机金属齿必须上蓝胶 (Loctite 243)**：
   - 双足机器人在行走震动时，无锁紧胶的螺丝会在 15 分钟内震松，导致齿轮打滑或骨骼脱落；
   - **注意**：塑料件螺丝切勿使用螺纹胶，否则化学腐蚀会导致塑料碎裂。
3. **线束活动余量与耐磨防护**：
   - 膝盖和大腿俯仰时关节活动范围近 90 度，总线线束必须预留 U 型弯曲余量，严禁紧绷拉扯插头。
