# yunyu-microUnit 项目知识库 (Knowledge Base)

本目录归档并整理了 **yunyu-microUnit**（现正式定名并标准化为**「灵方 (LingCube)」**微型自重构模块化机器人系统）相关的系统设计、机电方案、软硬件架构、能效评价、仿真平台搭建以及通用机器人与具身智能行业架构演进资料。

### 🏷️ 核心术语体系速查
- **独立物理单体 (1)**：**「灵方」 (LingCube)** —— 50mm 立方体微型自重构具身智能独立单元。
- **复合功能模块 (N)**：**「灵组」 (LingCluster)** —— 2~8 个灵方磁吸耦合构成的关节、轮组、足肢或感知模块。
- **宏观重构系统 ($\Sigma$)**：**「灵阵」 (LingMatrix)** —— 多个灵组（数十至数百灵方）协同构成的宏观可重构机器人超级集群系统。
- **多样化构型族谱 (Morphologies)**：**灵链** (线形/蛇形)、**灵环** (轮形/滚动)、**灵席** (二维平面网格)、**灵架** (三维立体晶格)、**灵步** (多足步行体)、**灵爪/灵臂** (操作末端)、**灵群** (离散游弋态)、**灵桩/灵坞** (基座母港)。
- **详细标准规范大案**：详见 [18_微型自重构机器人全生命周期命名体系与术语规范标准.md](./18_微型自重构机器人全生命周期命名体系与术语规范标准.md)。
