### 1.1 核心法则实装机理

1. **体积守恒与挤压拉伸 (Squash & Stretch)**：  
   物理世界中生物运动时形变但体积恒定。在下蹲蓄力与弹跳冲顶时，躯干半径满足严格体积守恒方程：
   $$W_{\text{body}} \times H_{\text{body}} = \text{Const} \quad \implies \quad R_x = \frac{R_{x0}}{\sqrt{S_y}}$$
   当下蹲挤压时，垂直方向压缩 $15\%$，水平躯干与脸颊自动向外膨胀膨化；起跳拉伸时横向收缩，还原果冻般 Q 弹质感。
2. **预备蓄力深蹲 (Anticipation Wind-up)**：  
   绝无突兀瞬间爆发动作。例如在「弹性跳跃」与「升龙霸天」等爆发性动作前，小熊必先经历持续 $25\%$ 周期的重力下潜（深蹲弯膝、双臂下摆、眼神专注盯地），积蓄势能后瞬间喷薄爆发。
3. **圆弧运动轨迹 (Natural Arcs)**：  
   肢体末端（左右熊爪、肉肉脚掌）轨迹全部遵循平滑样条圆弧（Arc Path），配合二次正弦谐波，绝无机械生硬的直线瞬移。
4. **跟随与次级动作 (Follow-Through & Secondary Action)**：  
   主体落地定格后，圆嘟嘟的双耳、粉嫩小肉垫与肚皮高光产生微幅衰减阻尼抖动，赋予角色鲜活生命感。
5. **极速零撕裂双缓冲 (Zero-Tear PSRAM Double Buffer)**：  
   依据公理三，全套动画在 ESP32-S3 8MB PSRAM 上的 135×240 精灵画布离线完成多层几何与阴影合成，DMA 单次原子推屏，消灭一切肉眼可见的 15Hz 撕裂与频闪，稳定输出 **85.1 FPS**！

## 4. 物理真机硬件操作与串口控制指南 (Hardware & Serial CLI)

### 4.1 真机物理按键操作

M5Stack StickS3 机身拥有两个高灵敏度微动按键：

```
       [ 135x240 LCD ]
      +---------------+
      |    JollyBot   |
      |   (o)   (o)   |
      |      w        |
      |   /|---|/\    |
      |               |
      |    [Btn A]    |  <-- 正面主按键 (M5 按键)
      +---------------+
             [Btn B]     <-- 侧面辅助按键 (PWR/Side 按键)
```

- **正面主按键 (Btn A)**：
  - **单击**：触发当前选定的主要动作（默认跳跃/元气挥手）；在小熊播音时单击，触发“物理打断打断音效”并立即转为专注聆听；
  - **长按 (1.5秒)**：单步切换到下一个姿态动作。
- **侧面按键 (Btn B)**：
  - **单击**：开启 / 停止全套动作自动阅兵巡礼 (Demo Showcase)；
  - **长按 (2秒)**：触发离线唤醒词「悄悄」仿真，进入语音交互对话态。

### 4.2 串口控制台命令行 (115200 波特率)

在电脑端连接 `COM3`，可通过串口控制台直接向真机下发交互指令：

```bash

>yaw=45                  # 调整偏航角为 45 度
>turn                    # 180 度掉头

# 4. 系统运行状态与自检查询
>status                  # 输出当前 FPS、内存、温度、姿态与等级状态
```
