## 1. 架构决策背景 (Architecture Decision Record - ADR)

### 1.1 问题现状与决策诱因
在《功夫学徒阿韧》的角色动作体系中，共规划了 22 套动作姿态：
- **7 套官方原画高精位图动作**（`idle` 静息站桩、`wave` 元气挥手、`bow` 作揖鞠躬、`kungfu` 中国功夫、`wingchun` 咏春快拳、`taichi` 太极云手、`dragon_punch` 升龙霸天，以及派生的 `cheer` 与 `clap`）；
- **15 套参数化过程化动作**（`sit` 盘腿坐下、`stretch` 伸大懒腰、`clap` 鼓掌、`cheer` 欢呼、`jump` 弹性跳跃、`hands_up` 举手投降、`dance` 律动跳舞、`balance` 金鸡独立、`lie` 趴地休息、`pushup` 俯卧撑、`moonwalk` 太空漫步、`cyber_defense` 机甲护盾、`turn_around` 转身秀尾、`spin` 华丽自旋、`locked_try` 困惑挠头）。

在本地高保真设计重构阶段，已基于 199px 金标坐标系生成了全套 15 套过程化动作概念图。然而，**受限于当前多模态模型与空间几何推理能力的阶段性局限**：
1. 复杂姿态（如坐姿盘腿、俯卧撑、平卧等地面姿态）的白色绸缎灯笼裤立体褶皱、膝盖曲面转折仍需极其细微的手工级曲线微调；
2. 动态肢体在 2D 屏幕投影时的前后深度次序与遮挡边缘，在极低分辨率（135×240）下仍易产生视觉噪点或局部比例失衡。

### 1.2 最终工程裁决 (Engineering Verdict)
- **正式设备端开放部署范围收敛**：
  为捍卫真机物理屏幕（ST7789）100% 呈现原画概念图影院级画质，**对 15 个过程化动作先做舍弃，不作为正式开放部署到设备端的代码**。设备端正式部署的动作巡礼（Showcase）与交互演示，全量锁定为官方原画位图姿态，杜绝任何未调优的半成品骨骼出现在用户面前。
- **固件优雅降级保护**：
  在 `firmware/m5sticks3_buddy/src/main.cpp` 的 `renderJollybot` 中建立生产防护门（`#if !ENABLE_EXPERIMENTAL_PROCEDURAL_CADET`）。若收到未开放动作指令，系统自动优雅降级为官方原画位图（`BEAR_ACT_IDLE` 站桩），保证 83+ FPS 极速运行与 0 画面异常。
- **项目级技术储备封存**：
  已建立的本地生成流水线、评估工具、199px 解剖学坐标系与三视画廊全部完好保存在仓库中，作为未来重大版本升级的核心资产。

## 4. 未来优化待攻坚技术细节清单 (Micro-Tuning Backlog)

当后续有充足研发精力或升级多模态能力时，需重点攻关以下关键瓶颈：

### 4.1 几何与布料解剖学微调
- [ ] **坐姿白绸下摆三次贝塞尔拟合**：针对 `03_sit` 姿态，重写下身坐姿网格，使用 4 段三次贝塞尔曲线绘制双膝盘曲处的布料垂坠折痕，消除平头胶囊感；
- [ ] **俯卧撑与贴地姿态的脊椎投影**：针对 `11_lie` 与 `12_pushup`，建立 3D 俯视斜向正交投影矩阵，让马甲与后背线条呈现自然的纵深透视；
- [ ] **单腿平衡（金鸡独立）的支撑脚受力形变**：针对 `10_balance`，给立地脚掌加入 2px 的挤压形变（Squash），强化迪士尼生物力学重量感。

### 4.2 表情与微动态质感微调
- [ ] **水光双星眼的亚像素微颤**：在 TTS 说话或聆听时，让主副高光星点产生 ±0.5px 的正弦轻微呼吸振动；
- [ ] **白颊羽簇的柔性跟随**：在身体左右晃动（`09_dance`, `20_spin`）时，给颊毛末梢加入 1 帧的滞后二次动作（Secondary Follow-Through）；
- [ ] **金爪印与金色滚边的动态光泽**：在主光源扫描时，给金色像素注入 1~2 帧的高亮反光过渡。

### 4.3 嵌入式显存与性能预算
- [ ] **DMA 双缓冲微片段渲染**：确保新几何渲染算法在 ESP32-S3 FreeRTOS 下每帧耗时 < 5ms，保障整体 FPS 维持在 80+ 以上；
- [ ] **Flash 空间受控**：若未来将部分微调动作转化为压缩增量位图，总增量需严格控制在 32KB 以内。

## 5. 重启研发准入条件 (Definition of Ready - DoR)

在未来重新开启该模块的固件移植前，必须满足以下硬性准入门槛：

1. **本地设计逐图精调完成**：15 套动作在 `cadet_procedural_designer.py` 中完成上述微调清单项；
2. **量化一致性评测 >= 98.0 分**：运行 `evaluate_cadet_consistency.py`，全套动作 9 维一致性得分均值达到 98 分以上；
3. **人工视觉评审签署（Gate Sign-off）**：用户在 `consistency_gallery.html` 中逐帧审查并明确批准；
4. **编译与硬件验证无阻**：固件烧录 `COM3`，在实机上维持 80+ FPS、0 I2C 故障与 160/160 全绿测试。
